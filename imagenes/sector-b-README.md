# Sector B Hamburguesas

Sitio web para hamburguesería artesanal con menú digital interactivo, galería de productos y botón de pedido directo por WhatsApp. Diseño orientado a la conversión.

## Stack

| Tecnología | Uso |
|---|---|
| Next.js | Framework principal |
| Tailwind CSS | Estilos y diseño responsivo |

---

## Funcionalidades

- Menú digital interactivo con categorías y productos
- Galería de imágenes de los productos
- Botón de pedido directo por WhatsApp
- Diseño mobile-first orientado a conversión
- Deploy en Vercel

---

## Instalación local

```bash
git clone https://github.com/nicopetito/sector-b-hamburguesas
cd sector-b-hamburguesas
npm install
npm run dev
```

Abrí [http://localhost:3000](http://localhost:3000).
